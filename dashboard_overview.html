分級概覽
綜合評分公式
Score = RP5D x 0.40 + CS x 0.30 - ES x 0.20 + StageBonus
RP5D = 5 日拉抬機率
CS = 控盤分數
ES = 出場風險分數（低佳）
StageBonus：吸籌 +5 / 拉抬 +3
指標與建議解析
【核心評分指標】
CS (控盤分數)：衡量主力對股票的控制力度與吸籌積極度。分數越高(>60)，籌碼越集中，易漲難跌。
RP (拉抬機率)：短線發動漲勢機率。分數越高(>80%)，壓力鍋即將掀開，隨時發動。
ES (出場風險)：主力趁高倒貨風險。分數越高(>40)，風險極大，主力可能正撤退。
【操作建議】
買進觀察：高控盤 + 低風險 + 有動能。最佳右側順勢買點。
農底觀察：股價跌入虧損攤平區且主力未放棄。最佳左側逆勢買點。
持有：主力溫和控盤，短線動能未出。耐心等待。
觀望：分數平庸無明顯訊號。建議避開。
減碼：進入獲利出貨區或高檔倒貨。盡速了結/避開。
